Tarea o hallazgo:
Se acepta T96 como mejora material de integridad: ocho validadores, fixtures negativos, cuarentena física y rechazo de los fallos históricos. No obstante, T96 no queda cerrado sin dos correcciones y T97 actual sólo puede contar como diagnóstico del recipe histórico.

1. Gate C es demasiado permisivo para claims probabilísticos:
- El fixture positivo acepta sólo 5 eventos y cobertura >=0.80.
- Cobertura de intervalos no calibra por sí sola P(score>=umbral), y cinco eventos no sostienen una probabilidad puntual ni una afirmación de 95%.
- Separar: (a) intervalos de score con cobertura prequential; (b) probabilidades de superar umbral con forecasts preregistrados y scoring Brier/logloss/calibration.
- Por defecto toda P pública/Q05 sigue NO_IDENTIFIABLE. No habilitar claims numéricos por el fixture de cinco eventos.
- Para una cota de 95%, exigir método y tamaño muestral que realmente produzcan esa cota; no hardcodear n=5/coverage=.8.

2. T97 actual mantiene leakage/shift interno en features apilados:
- fit_predict calcula ptxT = lr.predict_proba(XT) sobre las mismas filas/labels usadas para ajustar LR, y usa ptxT como feature para entrenar LGB y CatBoost; ptxP es out-of-sample. Esto es stacking in-sample y cambia la distribución fit/predict.
- seller/category TE para las filas de entrenamiento usa StratifiedKFold por fila. Para seller TE, otros registros del mismo vendedor quedan en train del subfold, mientras outer/inner validation contiene sellers completamente nuevos. El modelo aprende una señal de seller disponible en fit pero ausente en validación.
- Aunque outer-val no se filtra directamente, no es una base honestamente cross-fitted ni una réplica comparable para generalización. No promover resultados de este run.

3. T97 sólo evalúa vendedores nuevos: por construcción seen=0 en todos los outer-val. Es útil para el régimen new, pero no satisface la evaluación seen/new ni representa el ~69% seen reportado para test. Requiere un segundo protocolo congelado de seen-seller, por ejemplo holdout temporal/últimas filas dentro de sellers con historia disponible y features calculados sólo con pasado/fit.
