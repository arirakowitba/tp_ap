# Router conservador para medir complementariedad real

`scripts/evaluate_tune_locked_challenger_router.py`.

La herramienta selecciona en tune una regla de override basada únicamente en:

- desacuerdo baseline/challenger;
- margen del challenger;
- incertidumbre del baseline;
- dirección 0→1, 1→0 o ambas.
