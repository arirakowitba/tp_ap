## Material source audit

Inspection of `scripts/diagnose_s1_full_postmortem.py` confirms one valid computed finding:

- global in-sample Ridge text probabilities are compared with outer-fold OOF Ridge predictions, exposing a real in-sample/OOF gap.

However, the script does **not** compute most of the evidence claimed in AG-0151.

### 1. The “nested selector backtest” is not executed

Section 4 of the script only prints:

> pooled precision 50.3% (+1 net across 175 flips)

There is no code in that section that:

- fits the selector inside nested folds;
- freezes hyperparameters;
- selects 35 rows per fold;
- computes fixes/breaks;
- produces fold gains [-1,-1,-9,+7,+5];
- saves paired predictions.

Therefore the reported nested table is unsupported by the committed script.

### 2. Causal contribution percentages are hand-authored

The mechanism list contains literal strings such as ~5%, ~30%, ~40%, ~10%. No estimator, attribution method, ablation or counterfactual calculation produces them. The values overlap and are not a decomposition.

There is also an internal inconsistency:

- computed S1 split in the report is 103 seen / 47 unseen;
- the hard-coded M6 evidence says 50 seen / 100 global.

Treat all mechanism percentages as qualitative hypotheses, not measured contributions.

### 3. Bayesian/prequential recalibration is absent

The committed script does not fit a Bayesian or hierarchical calibration model. It does not update a likelihood from EVT-151 or compute posterior draws. Values such as:

- gamma_unverified=0.05;
- gamma_lexical=0.85;
- P=99.2%;
- Q05=0.94771;
- expected regret=0;
- EVSI=4.0 or 8.5 hits;
- expected max S5=0.95085

are hard-coded outputs without an auditable statistical derivation.

### 4. Strategy comparison is a literal table

All S2 alternative metrics are inserted as constants in `strat_table`. The code does not simulate the sequential policy, compute EVSI or evaluate the alternatives on frozen outer folds.

### 5. S2 is constructed from post-hoc manual test-title inspection

The six test rows are literal IDs selected by scripts that search test titles. No train-only rule family, nested phrase selection or outer-fold validation supports their declared probabilities. The observed S2 score of 0.94757 (-1 hit) empirically rejects the “zero-risk” certification.

The manifest inserts:

- estimated_flips_in_public=105;
- estimated_breaks=76;
- estimated_fixes=29;
- estimated_precision_public=0.283.

Only net public gain -46 is identified. The remaining values are not observed.
