# AP-2026-Q-2 · candidatos del 11 de noviembre de 2026

Los tres candidatos tienen 30.000 IDs válidos y se compararon por ID contra
S4/EVT-154 (0.94766). Las etiquetas de los candidatos salen de modelos
entrenados con etiquetas originales de train. Los scores históricos se
usaron para contrastar resultados agregados y dimensionar el riesgo.

## Entrenamiento y evaluación

- Train original 70.000 filas. Test original 30.000 filas.
- Un holdout de desarrollo de 19.892 IDs únicos, con 13.308 de vendedores
  excluidos del fit y 6.584 últimos ítems de vendedores con historia en fit.
- Dos refits completos. HistGB con texto NB-SVM agrupado por vendedor y
  Line 3 LightGBM con tres semillas, texto OOF y target encoding de vendedor
  calculado sólo con publicaciones de train estrictamente anteriores a cada
  timestamp evaluado. Enrutamiento seen/new por pertenencia al train.
- Line 3 enriquecida obtuvo 12.192/13.308 y 6.257/6.584 aciertos. La base
  Line 3 M0 obtuvo 11.558 y 6.085. Frente al HistGB enriquecido sobre las
  mismas filas, la ventaja fue +281 y +52, con Q05 de bootstrap por
  vendedor y categoría de +184 y +18 aciertos, respectivamente.
- La auditoría de AG halló cuatro copias de cada uno de los 8.023 IDs
  seen. Tras promediar las probabilidades por ID, Line 3 M1 obtiene 7.619
  aciertos frente a 7.395 de M0. La validación histórica y la de esta
  tanda son de desarrollo. El último split no certifica confirmación virgen.
- El argmax del blend histórico Podium discrepa con S4 en 2.651 IDs.
  Se excluyó como fuente de márgenes de S4.

## Interpretación de probabilidad

Con N público estimado en 20.998, superar 0.95000 exacto requiere +50
aciertos netos. Las probabilidades de la auditoría están condicionadas a una
fracción supuesta de flips correctos en todo test y a muestreo uniforme
sin reemplazo. Calculan únicamente la variación del subconjunto público.
La fracción real de flips correctos frente a S4 es desconocida. Los
intervalos de bootstrap del holdout miden diferencias de CV.

## Reproducción

Usar el archivo original con train_data.jsonlines y test_data.jsonlines y
los scripts de Antigravity en el commit
`098008b4d571fa3bdfaafc69a5ab5fa17cdd3b32`. Copiar los scripts de
preparación de split y Line 3 a `ag_source/scripts/` junto a este runner.
Los artefactos AG utilizados por el constructor son las tablas de test
de líneas 3 y 4, las tablas seen de líneas 3 y 4, la tabla unseen 70k de
Line 3, el test de ultimate_podium_engine_23h y el CSV S4.
Colocarlos como `inputs/{l3test,l4test,l3seen,l4seen,l3oof,podium,s4}.000`.
Se admiten varios fragmentos numerados si conservan los bytes y el orden.
Los JSON opcionales `inputs/history_*.json` contienen resúmenes por envío.

```sh
OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=1 python train_ap_today.py DATA.zip model_today
OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=3 python refit_ap_line3.py DATA.zip line3_today
OPENBLAS_NUM_THREADS=1 python build_ap_today.py --refit line3_today --out entrega_ap
```

Entorno de esta tanda: Python 3.12.14, scikit-learn 1.8.0, LightGBM 4.7.0.
